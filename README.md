# Проект "Мой проект Python"

## Описание:

Проект "Мой проект Python" - это приложение на Python для работы с банковскими операциями

## Установка:

1. Клонируйте репозиторий:
```
git clone https://git@github.com:SimonS62/Simon.git
```
2. Установите зависимости:
```
poetry install 
```
## Реализованный функционал:
* mask_card_number - маскирует номер карты
* mask_account_number - маскирует номер счета
* mask_account_card - маскирует реквизиты скрывая его номер 
* get_date - преобразует строку с датой в формате 'YYYY-MM-DDTHH:MM:SS' в 'DD.MM.YYYY'.
* filter_by_state - фильтрует список словарей по статусу операции
* sort_by_date - сортирует список словарей по дате операции

## Generators Module

Модуль `generators` предоставляет функции для работы с транзакциями и генерацией номеров банковских карт. Он включает в себя функции для фильтрации транзакций по валюте, генерации описаний транзакций и создания номеров банковских карт.

## Установка

Для установки модуля используйте pip:

```bash
pip install generators
```
## Реализованные функции:
* filter_by_currency - фильтрует список транзакций по заданной валюте.
* transaction_descriptions - возвращает описания для каждой транзакции.
* card_number_generator - генератор для создания номеров банковских карт в заданном диапазоне.
